Icon Description for Donorly Blood Donation App

1. Main Icon Elements:
   - A blood drop shape in bright red color (E53935)
   - A white medical cross symbol in the center of the blood drop
   
2. Design Variations:
   - Main icon: Blood drop on transparent background
   - Android adaptive icon foreground: Blood drop with white medical cross
   - Android adaptive icon background: Solid red color (E53935)
   
3. Size Requirements:
   - Original source image should be 1024x1024 pixels
   - Various sizes will be generated by the flutter_launcher_icons package

4. Style:
   - Flat, minimalist design
   - No gradients or shadows
   - Clean edges for clear visibility at small sizes

To generate the icon using the flutter_launcher_icons package:
1. Create the icon source files (donorly_icon.png and donorly_icon_foreground.png)
2. Place them in the assets/images directory
3. Run: flutter pub get && flutter pub run flutter_launcher_icons
